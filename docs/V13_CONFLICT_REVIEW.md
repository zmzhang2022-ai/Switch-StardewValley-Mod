## 已知关联与轻微风险

1. **可选按键重叠**：UI 的“按住左摇杆才显示范围”读取 L3（0x40），钓鱼组合键为 L3+R3（0x40+0x80）。若打开该选项且满足范围显示条件，按钓鱼组合键也可能显示范围提示；它没有消费按键或阻止钓鱼。HoldRanges 默认关闭。证据：`ranges.cpp:90`、`fishing.cpp:71`。
2. **HUD 遮挡风险**：每日信息从 (24,24) 向下扩展，钓鱼提示固定在 (16,170)，没有根据每日信息高度避让；信息较多时可能覆盖。属于静态布局风险，未在真机复现。证据：`hud.cpp:207`、`fishing.cpp:328`。
3. **UI 依赖**：钓鱼状态提示由 UI HUD 绘制；普通菜单打开时 HUD 被隐藏。NPC 地图也经 UIInfo::Install 安装；UI 总安装指纹失败会连带跳过 NPC 地图。钓鱼的逻辑安装独立于 UI。
4. **共享进程与性能**：所有功能共用进程和 Hook 池，不具备崩溃隔离。地图开启时角色扫描与绘制的真机帧率尚未测量；静态无冲突不能证明没有性能影响。
