# NPC Map Locations — Switch 大地图整合版 v13

日期：2026-09-16。状态：原生实现、静态检查、本地构建及产物校验通过；真机验收未执行。

## 一、已确认的需求

- 基于现有 v12.1 整合包，新增 NPC Map Locations 大地图人物追踪。
- **不做常驻小地图**，也不添加小地图开关或快捷键。
- **允许显示尚未认识、剧情隐藏的人物**，不采用 PC 默认的认识/剧情条件过滤。
- 保留 L3+R3 自动钓鱼以及满力度、铱星修复；机器自动化、电梯、四戒指、其他 UI 功能继续使用原源码。
- 参考目录实际为 `D:/Switch_StardewVally/PCmod/NPCMapLocations`，参考版本 3.5.2，作者 Bouhm。PC DLL 只用于语义分析，不能在 Switch 原生运行，也不装入交付包。
- 沿用项目已确认的单人范围。目标 Switch Stardew Valley 1.6.15.3，main Build ID `A5C617C14A7F3F6620B3BC8136965A4822D32B9C`。

## 二、用户看到的功能

| 项目 | 完整方案及当前代码行为 |
| --- | --- |
| 入口 | 正常打开游戏大地图，无需新组合键 |
| 人物标记 | 原版角色精灵中的正面头像；复用游戏自己的头像裁切规则，包括孩子的重载。无贴图时回退姓名首字 |
| 人物范围 | 已加载位置及已实例化室内中的村民、剧情 NPC、马和孩子；另外检查正在骑乘的马；排除怪物 |
| 隐藏人物 | 不检查是否认识、不按剧情锁隐藏；尊重玩家原先手动关闭的逐 NPC 追踪 |
| 人物位置 | 原版 WorldMapManager 坐标映射及当前地图区域匹配；室内按原版入口/区域规则定位，姜岛按岛屿区域定位 |
| 重叠人物 | 图标保持实际锚点；悬停时显示同一重叠组的完整名单，最多每页 8 人，过长每 3.5 秒自动翻页 |
| 人物详情 | 姓名、生日、每日委托、今日交谈、今日送礼、好感心数；未建立好感记录时明确显示该状态 |
| 生日/任务 | 生日边框及“生”标记、每日委托边框及“!”标记；同时存在时头像优先生日，详情列出两者 |
| 每日委托范围 | 已接受、未完成的每日送货/杀怪/钓鱼/采集任务，对应具体目标人物；不把所有剧情任务都标成可交付 |
| 商人 | 旅行商人、书摊老板在当天营业时显示，使用原模组对应的原版图标和地图位置 |
| 玩家头像 | 保留原版绘制 |
| 总开关 | 现有 UI 信息设置 → 地图村民位置；关闭后恢复原版地图头像/提示流程 |
| 逐人开关 | 沿用现有社交页“地图 ✓ / ×”及每存档配置；不改变配置格式、不重置已有偏好 |

这里的“全部显示”指不额外用认识/剧情条件隐藏**已经存在且可定位**的人物；不会生成尚未生成的角色、打开未加载的房间、解锁区域或修改剧情。没有原版地图映射的角色跳过，避免伪造位置。陌生人物若未出现在社交页，只能用总开关控制，当前没有新增独立人物管理面板。

这是一份按用户选择裁剪后的大地图完整版：不包含 PC 小地图、联机玩家同步、SMAPI/GMCM、模组自定义地图包、农场建筑图标、任意尺寸/透明度配置及额外好感/交谈筛选菜单。保留原版地图建筑底图；不会把这些未实现项目写成已移植。

## 三、实现结构与互不干扰边界

```text
原版 MapPage.draw
  ├─ 原版 drawMap：地图、区域、缩放
  ├─ drawMiniPortraits Hook：原版玩家头像 → NPC 头像/悬停组
  └─ drawTooltip Hook：人物悬停显示名单；其他情况调用原版提示
```

- 替换旧 `uiinfo/npc_map.cpp` 的首字标记实现，不叠加第二套 NPC 标记。
- 旧 Hook 在整个地图画完后绘图；新 Hook 在地图自己的变换矩阵内画头像，随后在原版提示阶段画信息框。
- 不新增 Tick 工作，不接管手柄输入，不写人物位置、背包、关系、任务、剧情、存档字段。
- 相比 v12.1，已有运行源码仅改 `uiinfo/npc_map.cpp` 和版本字符串；新增 `npc_map_logic.hpp`、`npc_map_signatures.hpp`。其余 253 个已有源码文件保持字节一致。
- 保守 Hook 数从 31 增至 32；池仍为 8192 字节 / 40 槽，余 8 槽。最终 ELF 校验步长 200、索引超过 39 拒绝，未扩池。
- 各功能仍在同一游戏进程中，不承诺崩溃隔离。地图关闭时，本模块没有后台刷新工作。

## 四、数据与缓存

- 每次头像绘制重新从游戏根集合取得当前角色引用，回调结束不保存托管引用。
- 缓存只包含复制的 UTF-16 字符、坐标、裁切矩形、生日/任务状态和索引。
- 人物位置/详情缓存 500 ms；存档 ID、日、季、年、地图区域变化立即失效。开关关闭后，下次开启刷新。
- 单次最多 256 个角色/标记、64 个每日委托目标；原版单人足够。不是无限扩展 NPC 模组兼容承诺。
- 头像贴图在本次回调重新取得；不长期保存 Texture2D、NPC、MapRegion 或任务对象指针。
- 特殊商人使用原版营业判定和 PC 3.5.2 的图标/位置定义；查找已加载 Town/Forest，不调用创建地图的接口。

## 五、关键 ABI 与证据

| 项目 | 核实结果 |
| --- | --- |
| drawMiniPortraits | body `0x173C7F0`，`page=x0, batch=x1, alpha=s0`；原版调用点 `0x173C674..690` |
| drawTooltip | body `0x173DD40`，page/batch；原版调用点 `0x173C6F0..708` |
| 地图范围 | mapBounds `+0xA4` 的宽高是贴图单位，drawMap `0x173D2DC..2FC` 乘四；GetMapPixelPosition 已返回显示单位，不二次乘四 |
| 坐标映射 | `0x1B0E7B0` 接受 location、8 字节 Point，32 字节 NullablePosition 经 x8 返回；`0x1B0CC70` 返回 HFA Vector2 |
| 是否村民 | NPC 基类 `0x18F0510` 恒返回 true，必须按 invoker `0x74A96E8` 使用虚槽 `0x110`，避免怪物混入 |
| 头像裁切 | invoker `0x74AD3D8` → 虚槽 `0x560`，16 字节 Rectangle 经 x0/x1 返回；孩子重载 `0x1192790` |
| 精灵 | Character.get_Sprite invoker `0x71DA5C0` → 虚槽 `0xE0`，AnimatedSprite.Texture body `0x10FF650` |
| 任务集合 | Farmer `+0x1B0` 是具体 NetObjectList<Quest>；Count `0x36C62B8`，get_Item `0x36C61A0`，使用拥有者解包 |
| 任务判定 | Quest accepted/completed/dailyQuest 为 `+0x30/38/40` NetBool；四个任务类型的 target 分别为 `+0xB0/A8/B8/A8` NetString，经具体类型判断后读取 |
| 商人 | Forest `0x158F0E0/0x158F140`；书商日历 `0x1AE9B30` 返回具体 List<int>，Count `0x3EC9C58`、Item `0x839F0` |
